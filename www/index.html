Servidor HTTP/1.1 implementado en C

Servidor funcionando

Si ves esta página, el servidor HTTP está corriendo correctamente.

Características implementadas

  • Método GET con parsing HTTP/1.1
  • Archivos estáticos (HTML, CSS, JS, imágenes)
  • Múltiples clientes con epoll
  • Conexiones persistentes (keep-alive)
  • Tipos MIME automáticos
  • Protección contra Directory Traversal
  • Códigos de estado: 200, 400, 403, 404, 405, 500
